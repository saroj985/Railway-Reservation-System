# Railway Reservation System

Write a Java program and save records to the database using hibernate
annotation. (Time 1hr 30min)
Create a new Project under ‘zorba_exam_submission’ and submit via
GitHub.
Objective : Railway Reservation Systems
Passenger will be reserving tickets. There 3 types of passenger available
a. General (passenger_id, name, email, mobile, destination, seat_number,
coachType)
b. Senior Citizen(passenger_id, name, email, mobile, destination, seat_number,
discount, senior_citizen_id)
c. Physically handicapped(passenger_id, name, email, mobile, destination,
seat_number, proof_of_disability)
They all can reserve seats in train. But seat allocation will be based on the
passenger type.
Create required tables and store passenger info in the database. Considering all
tables would be connected.
1.Take input via scanner.
2.In each type Store 3 passenger.
3.Save all the information to Database.
4.Fetch the Physically handicapped passengers details and display in
   console.
